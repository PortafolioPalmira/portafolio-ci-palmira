# Portafolio C.I. Palmira — sitio estático

Este prototipo funciona con HTML, CSS y JavaScript puro. No requiere servidor ni base de datos.

## Estructura

```text
index.html
style.css
script.js
data/portafolio_proyectos.csv
```

## Actualización de datos

1. Actualiza la matriz en Excel.
2. Exporta la hoja `Portafolio_Proyectos` como CSV UTF-8.
3. Renombra el archivo como `portafolio_proyectos.csv`.
4. Reemplaza el archivo ubicado en `data/`.
5. Sube los cambios a GitHub.

## Publicación en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube todos estos archivos.
3. En `Settings > Pages`, selecciona la rama principal y la carpeta raíz.
4. Guarda la configuración.

GitHub publicará la página con una URL del tipo:
`https://usuario.github.io/repositorio/`
